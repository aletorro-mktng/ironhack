For this lab, I refactored the product listing generator from Path 1, the original working script in `NEW LAB/product_listing_generator.py`, into Path 2, the modular version in `NEW LAB/product_listing_generator_refactored.py`. I split the workflow into focused helpers for loading product rows, validating paths/images/product data with Pydantic, processing products, building OpenAI prompts and inputs, parsing responses, formatting success/failure results, and saving output; I also improved error handling so missing files, malformed JSON, invalid product data, and API failures show clearer location, message, and suggestion details. The main challenge was keeping the original behavior working while separating responsibilities without breaking the API/mock workflow, and I learned that refactoring is easiest when each function has one reason to change and test cases cover both successful and failing paths.
