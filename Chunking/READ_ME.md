# Different Ways to Chunk Podcast and PDF Lab

This repository contains a Jupyter notebook for comparing different text chunking strategies for a podcast transcript and a PDF document about Trustworthy AI.

## Files

| File | Description |
|------|-------------|
| `chunking_strategies.ipynb` | Main notebook with all code, chunking strategies, tables, visualizations, and analysis. |
| `podcast_transcript.txt` | Transcript generated from the podcast audio file. |
| `ai_hleg_ethics_guidelines_for_trustworthy_ai-en_87F84A41-A6E8-F38C-BFF661481B40077B_60419.pdf` | PDF document used for chunking analysis. |
| `lab_summary.md` | Short final summary of recommendations and trade-offs. |
| `requirements.txt` | Python package dependencies needed to run the notebook. |

## How to Run

1. Clone this repository.

2. Create and activate a virtual environment:

python3 -m venv .venv
source .venv/bin/activate
