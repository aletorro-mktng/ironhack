# Mortal Vengeance Book 1 Character Portraits

Solid-background character portraits used by Mythos for quote graphics, pull quotes, character spotlights, blog visuals, and social previews.

The canonical registry lives in `src/character_assets.py`. Add new portraits with snake_case filenames and map them in `BOOK1_CHARACTER_PORTRAITS`.
