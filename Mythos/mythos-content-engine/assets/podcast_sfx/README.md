# Podcast Sound Effects Library

Place licensed podcast sound effects here.

Supported formats: `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`.

Recommended naming:

- `camera_shutter_soft.wav`
- `page_turn_close.mp3`
- `distant_church_bell_low.wav`
- `tape_click_analog.mp3`

Files in this folder appear in the Podcast Options sound effects checklist. Selected SFX files are included in the production ZIP for placement during final editing.
