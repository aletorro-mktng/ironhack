# Podcast Music Library

Place licensed intro and outro music files here.

Supported formats: `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`, `.flac`.

Recommended naming:

- `grim_talk_dark_intro_08s.mp3`
- `mortal_vengeance_warm_outro_12s.wav`
- `award_dispatch_low_strings_10s.mp3`

Files in this folder appear in the Podcast Options music dropdowns. When selected, local music files are stitched into the full podcast MP3 and included in the production ZIP.
