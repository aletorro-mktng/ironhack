# Quote Usage Rules

## Allowed

- Use exact quotes listed in this file.
- Attribute quotes to the correct book and character when available.
- Use spoiler-safe quotes for public marketing.
- Use mood tags, character tags, and book tags to select the right quote.
- Use quote context to write captions or visual directions.

## Not Allowed

- Do not invent dialogue.
- Do not invent narrator lines.
- Do not attribute a quote to a character unless listed.
- Do not use spoiler-heavy quotes in public-facing content unless explicitly requested.
- Do not mix real review quotes with book quotes.
- Do not label generated promotional copy as a book quote.
