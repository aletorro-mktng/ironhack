This RAG implementation uses OpenAI native APIs to load a Trustworthy AI PDF and podcast transcript, chunk them into token-based segments, generate embeddings with `text-embedding-3-small`, and store them locally in `embeddings_store.json`. For retrieval, the system embeds the user query, calculates cosine similarity against all saved chunk embeddings, returns the most relevant chunks with source tracking, and passes that context into an OpenAI chat completion to generate a grounded answer. The main design choice was to keep the pipeline simple and transparent by using local JSON storage instead of a vector database, which makes the retrieval process easier to inspect while still demonstrating the complete RAG workflow.
